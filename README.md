# QUDRA · قُدرة
### منصة الكفاءات المبنية على الأدلة والمطابقة المُفسَّرة (Evidence-Backed Capability Platform)

> **الإصدار:** v2.0  
> **اللغات:** العربية (RTL افتراضي) + الإنجليزية (LTR)  
> **التقنيات:** React 19 · Vite · Lucide Icons · CSS Design System

---

## 📌 عن المشروع (About QUDRA)

**قُدرة** هي منصة متقدمة تهدف إلى حل أزمة الثقة في أسواق العمل والتوظيف عبر **محرك أدلة موحد (Unified Evidence Engine)** يربط إثبات الكفاءة الذاتية بالحل الفعلي للمشكلات الواقعية وفق ركيزتين أساسيتين:

```
+-----------------------------------------------------------------------------------------+
|                                    منصة قُدرة (QUDRA)                                    |
|                     محرك الأدلة الموحد (Unified Evidence Engine)                        |
+-------------------------------------------+---------------------------------------------+
                                            |
             +------------------------------+------------------------------+
             v                                                             v
+-----------------------------------------+   +-----------------------------------------+
|       الركيزة الأولى (Pillar 1)          |   |       الركيزة الثانية (Pillar 2)         |
|   الملف الذكي وجواز القدرات الرقمي      |   |        المشكلة ← المطابقة المُفسَّرة    |
|       (Capability Passport)             |   |     (Problem -> Explainable Match)      |
+-----------------------------------------+   +-----------------------------------------+
| • موصلات بمستويات ثقة (Official/User/Fragile)| • تفكيك المشكلة التقنية دلالياً          |
| • تصنيف ثلاثي: Proven / Claimed / Gap   | • مطابقة بالأدلة مع درج تفسير XAI        |
| • كشف الفجوات ومسار "الخطوة القادمة"    | • مُركِّب الفرق التكاملي (Team Composer) |
| • رابط محمول مقروء للبشر وللـ AI        | • تحويل تسليمات المشاريع لأدلة جديدة     |
+-----------------------------------------+   +-----------------------------------------+
```

## 🚀 التشغيل السريع محلياً (Quick Start)

### المتطلبات الأساسية:
* **Node.js** (v18 فما فوق)
* **npm** أو **pnpm** أو **yarn**

### خطوات التشغيل:
```bash
# 1. الانتقال إلى مجلد التطبيق
cd qudra-app

# 2. تثبيت الحزم التابعة (إذا لم تكن مثبتة)
npm install

# 3. تشغيل خادم التطوير الحي
npm run dev
```

التطبيق سيعمل فورياً على المتصفح عبر:
👉 **`http://localhost:5173/`** (أو `http://localhost:4173/` لخادم المعاينة).

## 🧭 مستعرض الشاشات الـ 1,040 (The 1,040 Screen Explorer)

وفقاً لمواصفات المشروع، تنقسم المنصة إلى:
* **26 وحدة وظيفية (M01 - M26)**
* **40 حالة تفاعلية وحافة لكل وحدة**
* **156 شاشة ارتكاز (Anchor Screens ⚓)** تغطي الحالات الست الأساسية لكل وحدة: (نظرة عامة، تفاصيل، إنشاء، نتائج، حالة فارغة، حالة خطأ).

يحتوي النموذج الأولي المبرمج على **مستعرض شاشات مدمج (`ScreenNavigator`)** يتيح التنقل المباشر لأي شاشة بالرمز التسلسلي الدقيق (`Q-0001` إلى `Q-1040`) ومطالعة النمط المرجعي المأخوذ من المنافسين.

## 🎨 هوية التصميم وتجربة المستخدم (Design System & UX)

* **راحة العين والهدوء البصري (Calming & Airy Aesthetics):** خلفيات بيضاء ناعمة وظلال خفيفة بالغة النعومة، بعيداً عن التدرجات الداكنة الثقيلة أو الحواف الفاقعة المزعجة.
* **اللغة العربية أولاً (Arabic-First RTL):** طباعة عربية متزنة وخطوط واضحة (`IBM Plex Sans Arabic` و`Cairo`) مع خواص منطقية تدعم التبديل السلس للإنجليزية (LTR).
* **قاعدة المصداقية (Proven ≠ Claimed):** تمييز بصري صريح بين ما هو مثبت بأدلة، وما هو معلن ذاتياً، وما هو فجوة قائمة.
* **درجات ثقة الموصلات:** تصنيف واضح بين الموصلات الرسمية (OAuth)، والملفات المرفوعة، والروابط التقنية الحساسة، مع حظر كامل للسكرابينغ العشوائي.

## 🤝 آلية التسليم لفريق التطوير (Developer Handover)

عند تسليم هذا المشروع لجهة العمل أو فريق تطوير الواجهات الخلفية (Backend & Production Team)، يتم الاستناد إلى دليل التسليم المرفق في [`docs/developer-handoff.md`](docs/developer-handoff.md)، والذي يوضح:
1. **نماذج البيانات الصريحة (TypeScript Schemas):** لكائن الدليل، وجواز الكفاءات، وتفكيك المشكلات.
2. **بوابات الربط الحقيقية:** موصلات OAuth 2.0 PKCE، وبوابات الدفع والضمان المالي المحلية (مدى، STC Pay، فوري).
3. **محرك الاستدلال والتفسير (XAI):** تغذية درج التفسير بالأوزان وعوامل التحسين (Counterfactuals).
