# مواصفة الشاشات: الوحدة M02 — الصفحة الرئيسية (Home Dashboard)
## Module Specification: M02 Home Dashboard · P0

**معرفات الشاشات المرجعية:** Q-0041 (Overview ⚓), Q-0043 (Details ⚓), Q-0044 (Create ⚓), Q-0047 (Results ⚓), Q-0069 (Empty ⚓), Q-0071 (Error ⚓)  
**المسار:** `/home`  
**الأدوار المدعومة:** دور المهندس (`role === 'u'`) · دور المنشأة وصاحب المشكلة (`role === 'c'`)

---

### 1. الغرض الأساسي ومهمة المستخدم (Screen Purpose & Intent)
- **للمهندس:** تقديم منصة قيادة مهنية فورية توضح أين وصلت قدراته، ما هي الأدلة المسجلة والموثوقية، وإبراز أعلى 3 فرص عمل/مشاريع متطابقة مع كوده بنسبة 80% فما فوق، مع إمكانية الوصول السريع لمركز الأدلة، وجواز القدرات، ومختبر التحديات.
- **للمنشأة:** مدخل مباشر لطرح مشكلة تقنية للتحليل الفوري، مع استعراض قائمة مختصرة للمرشحين المطابقين بالأدلة والمشاريع السابقة، والوصول لأدوات تكوين الفرق وخط أنابيب التوظيف.

---

### 2. التكوين البصري والواجهة الفاتحة (Light-First Visual Composition)
- **الخلفية العامة:** `--ground` (`#F8FAFC`).
- **الترويسة والبطاقات:**
  - بطاقة الهوية العلوية: سطح أبيض نقي (`#FFFFFF`) مع إطار رمادي ناعم (`#E2E8F0`) وظل خفيف (`box-shadow: 0 1px 3px rgba(15, 23, 42, 0.05)`).
  - شبكة المقاييس (Metrics Strip): 3 بطاقات متوازية (عدد الأدلة، نسبة الموثوقية العامة، الفرص المتطابقة)، مع شارة دائرية خضراء للموثوقية وأيقونات واضحة.
  - منصة الإطلاق السريع (Launchpad Grid): 4 بطاقات تفاعلية ذات ألوان دلالية خفيفة في الأيقونات لتمييز الوجهة (سوق الفرص: فيروزي، مركز الأدلة: رمادي ناعم، جواز القدرات: كهرماني، مختبر التحديات: زمردي أخضر).
  - بطاقات الفرص المتطابقة (Opportunity Cards): تنظيم أفقي بارز لنسبة التطابق مع ذكر الراتب وموعد التسليم وشعار المنشأة الموثقة.

---

### 3. الطباعة والمحتوى (Typography & Content Hierarchy)
- اسم المهندس / المنشأة: `IBM Plex Sans Arabic` وزن 700، حجم `1.35rem`.
- درجات الموثوقية والأرقام: `IBM Plex Mono` داخل كبسولات مريحة للعين.
- العناوين الفرعية: وزن 400 بلون رمادي وقور (`#334155`).

---

### 4. أنماط المنافسين المعتمدة (Competitive Inspiration)
- **LinkedIn:** ترويسة الهوية الموثقة، شارة التحقق الخضراء، وزر التعديل ومشاركة الجواز.
- **Upwork:** بطاقات مطابقة الوظائف مع ذكر نطاق الأجر ونسبة المواءمة.

---

### 5. شاشات الـ Anchor الستة الخاصة بـ M02
1. **Q-0041 (نظرة عامة Overview ⚓):** العرض التكيفي الرئيسي للمهندس أو المنشأة.
2. **Q-0043 (التفاصيل Details ⚓):** عرض تفصيلي لمؤشر الموثوقية الهندسية وتفكيكه.
3. **Q-0044 (إنشاء Create ⚓):** نموذج بدء مشروع أو هدف مهني جديد.
4. **Q-0047 (النتائج Results ⚓):** تقرير المطابقة الإجمالية لليوم.
5. **Q-0069 (الحالة الفارغة Empty ⚓):** تظهر عندما لا توجد أدلة بعد مع دعوة صريحة "اربط أول مستودع GitHub".
6. **Q-0071 (معالجة الخطأ Error ⚓):** إشعار تعذر الاتصال بمزود البيانات مع زر إعادة المحاولة الفوري.
