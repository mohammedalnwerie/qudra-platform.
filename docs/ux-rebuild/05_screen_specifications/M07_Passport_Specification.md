# مواصفة الشاشات: الوحدة M07 — جواز القدرات المعتمد (Capability Passport)
## Module Specification: M07 Capability Passport · P0

**معرفات الشاشات المرجعية:** Q-0241 (Overview ⚓), Q-0243 (Details ⚓), Q-0244 (Create ⚓), Q-0247 (Results ⚓), Q-0269 (Empty ⚓), Q-0271 (Error ⚓)  
**المسار:** `/passport`  
**الأدوار المدعومة:** الجميع (المهندس وصاحب العمل والزوار الخارجيون ونماذج الـ AI)

---

### 1. الغرض ومهمة المستخدم
- إتاحة وثيقة هوية رقمية واحدة وموحدة تجمع كافة أدلة الشخص من مصادر متعددة (GitHub, Coursera, Hack The Box...).
- توفير "سياق الذكاء الاصطناعي الفوري" (AI Context Layer) الذي يمكن نسخه بضغطة زر وتمريره لأي أداة (ChatGPT, Claude) ليفهم مسار المهندس وكوده دون الحاجة لشرح مطول.
- إبراز تفكيك الـ DNA الهندسي بمقاييس متعددة العوامل (Multi-Factor Scoring).

---

### 2. التكوين البصري في المظهر الفاتح (Light-First Visual Composition)
- **بطاقة سياق الـ AI العلوية:** خلفية فيروزية رقيقة جداً (`#E6F8F8`) بإطار `#B2EBF2` مع زر رئيسي مشع لنسخ الـ Prompt وزر لمشاركة الرابط العام.
- **ترويسة جواز السفر (Passport Header):**
  - رقم تسلسلي معتمد: `QDR-2026-963-8`.
  - شعار قُدرة الرسمي مع وسم "وثيقة الكفاءات الحية القائمة على الأدلة البرمجية - بديل السيرة الذاتية التقليدية".
  - اسم المهندس، المسمى الوظيفي، المدينة، ونسبة الموثوقية الشاملة (`88%`).
- **شبكة البراهين والـ DNA الهندسي:**
  - عمود مصادر الأدلة المربوطة والمحققة (GitHub، شهادات Meta & Coursera، مشاريع البورتفوليو).
  - عمود تفكيك الـ DNA الهندسي بأشرطة تقدم متناسقة (الأدلة العملية 40%، المشاريع المنجزة 30%، التقييم المعماري والشفهي 20%).

---

### 3. شاشات الـ Anchor الستة الخاصة بـ M07
1. **Q-0241 (نظرة عامة Overview ⚓):** العرض الشامل لجواز القدرات القابل للتصدير والمشاركة.
2. **Q-0243 (التفاصيل Details ⚓):** فحص عميق لأي دليل داخل الجواز مع الرابط التوثيقي الأصلي.
3. **Q-0244 (إنشاء Create ⚓):** إنشاء وتخصيص رابط جواز جديد وتحديد نطاق الظهور (Public / Private / Token).
4. **Q-0247 (النتائج Results ⚓):** سجل الزيارات ومشاهدات الجواز من أصحاب الأعمال.
5. **Q-0269 (الحالة الفارغة Empty ⚓):** عند عدم وجود مصادر مربوطة، مع خطوات سهلة لإضافة أول مصدر.
6. **Q-0271 (معالجة الخطأ Error ⚓):** عند فشل التحقق من التوقيع المشفر للجواز مع زر إعادة التحميل.
