# مواصفة الشاشات: الوحدة M15 — إدخال المشكلة وتحليلها (Problem Input & Analysis)
## Module Specification: M15 Problem Input & Analysis · P0

**معرفات الشاشات المرجعية:** Q-0561 (Overview ⚓), Q-0563 (Details ⚓), Q-0564 (Create ⚓), Q-0567 (Results ⚓), Q-0589 (Empty ⚓), Q-0591 (Error ⚓)  
**المسار:** `/problem`, `/problems/match-report`  
**الأدوار المدعومة:** صاحب المشكلة / المنشأة (`c`)

---

### 1. الغرض ومهمة المستخدم
- إتاحة مدخل ذكي وسهل لأصحاب المشكلات التقنية لوصف ما يحتاجونه بلغتهم العادية وبدون تعقيد مصطلحات برمجية.
- قيام الذكاء الاصطناعي بتفكيك النص لاستخراج الهدف، والقيود، والقدرات المطلوبة تلقائياً.
- **حل فخ مسار المنشأة (Problem Owner Trap):** النتيجة المباشرة لتحليل المشكلة هي إظهار **«المرشحين المطابقين بالأدلة»** (`/candidates`)، مع عدم إجبار صاحب المشكلة على دخول محاكاة حل الكود إلا إذا كان يريد ذلك كخيار استكشافي إضافي.

---

### 2. التكوين البصري والواجهة الفاتحة (Light-First Visual Composition)
- **محرر إدخال المشكلة:**
  - عنوان واضح: «ما المشكلة التي تريد حلّها؟».
  - مساحة نصية مريحة وواسعة مع عداد أحرف (`69 / 2000`) ومؤشر الوقت المتوقع للتحليل (`متوسط الزمن 14 ثانية`).
  - أمثلة سريعة للبدء بنقرة واحدة (تطبيق جامعي، تحليل مكالمات، متجر إلكتروني).
  - لوحة توضيحية جانبية تشرح ما يحدث بعد الضغط (1. نفكك نصك، 2. نولد لك محاكاة، 3. نطابق لك الكفاءات بأدلة مثبتة).
  - زر الإجراء الأساسي: «حلّل المشكلة» مع زر عودة صريح للرئيسية.

---

### 3. شاشات الـ Anchor الستة الخاصة بـ M15
1. **Q-0561 (نظرة عامة Overview ⚓):** شاشة إدخال المشكلة الذكية.
2. **Q-0563 (التفاصيل Details ⚓):** تقرير تفكيك المشكلة واستخراج المهارات المطلوبة.
3. **Q-0564 (إنشاء Create ⚓):** تخصيص مسألة جديدة مع تحديد الميزانية والمواعيد.
4. **Q-0567 (النتائج Results ⚓):** تقرير مطابقة المشكلة مع القدرات وسوق المواهب.
5. **Q-0589 (الحالة الفارغة Empty ⚓):** نص المشكلة فارغ مع إبراز أمثلة جاهزة لملء النموذج.
6. **Q-0591 (معالجة الخطأ Error ⚓):** تنبيه بنقص تفاصيل المشكلة مع اقتراحات لزيادة دقة التحليل.
