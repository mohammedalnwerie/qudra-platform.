# مواصفة الشاشات: الوحدة M16 — المطابقة المُفسَّرة وقائمة المرشحين (Explainable Matching & Candidates)
## Module Specification: M16 Explainable Matching · P0

**معرفات الشاشات المرجعية:** Q-0601 (Overview ⚓), Q-0603 (Details ⚓), Q-0604 (Create ⚓), Q-0607 (Results ⚓), Q-0629 (Empty ⚓), Q-0631 (Error ⚓)  
**المسار:** `/candidates`, `/matching/m16`  
**الأدوار المدعومة:** صاحب المشكلة / المنشأة (`c`) · المراجع الهندسي

---

### 1. الغرض ومهمة المستخدم
- عرض قائمة المرشحين للمشكلة البرمجية مرتبين وفق قوة الأدلة المثبتة، مع تبيان الفجوات المهارية بشفافية.
- تمكين المنشأة من استكشاف سبب ترشيح كل مهندس بضغطة زر عبر درج الشرح (`Explain Drawer`).
- إمكانية تكوين فريق هندسي متكامل يغطي جميع جوانب المشكلة أو دعوة المرشح مباشرة.

---

### 2. التكوين البصري والواجهة الفاتحة (Light-First Visual Composition)
- **شريط الرأس والأدوات:**
  - العنوان: «المرشحون المطابقون لمشكلتك بالأدلة».
  - الوصف: «ترتيب فوري معلل مبني على فحص الكود الحقيقي والمشاريع السابقة — لا على ادعاءات السيرة الذاتية».
  - أزرار الإجراءات: زر مميز «تكوين فريق متكامل» بأيقونة براقة، وزر «مقارنة بصميّ مرشحين».
  - فلاتر سريعة: كافة المرشحين (5)، جاهزون فوراً (1)، تطابق قريب — فجوة واحدة (2).
- **صفوف المرشحين (Candidate Rows):**
  - رقم الترتيب التصاعدي: `01`, `02`, `03` بخط `IBM Plex Mono`.
  - الأفاتار، والاسم، والمسمى الوظيفي، والمدينة.
  - كبسولات الأدلة المثبتة مع عدد المشاريع: `9 Database`, `5 Backend`, `4 REST APIs`.
  - شارة نسبة التوافق المعلل: `84% توافق معلل`، وحالة الجاهزية `جاهز للبدء الفوري`.
  - زر الاستكشاف: «لماذا رُشّح؟» (يفتح Explain Drawer).
  - زر الإجراء النهائي: «دعوة للمشروع».

---

### 3. شاشات الـ Anchor الستة الخاصة بـ M16
1. **Q-0601 (نظرة عامة Overview ⚓):** قائمة المرشحين المفرزة والمصنفة بالأدلة.
2. **Q-0603 (التفاصيل Details ⚓):** الملف المقارن للمرشح مقابل متطلبات المسألة بالتفصيل.
3. **Q-0604 (إنشاء Create ⚓):** تخصيص معايير الترشيح وأوزان التقييم (مثلاً: إعطاء وزن أكبر لقواعد البيانات).
4. **Q-0607 (النتائج Results ⚓):** تقرير المطابقة المعمارية النهائي.
5. **Q-0629 (الحالة الفارغة Empty ⚓):** عند عدم وجود مرشحين يتطابقون مع متطلبات غير واقعية، مع اقتراح تخفيف القيود.
6. **Q-0631 (معالجة الخطأ Error ⚓):** تعذر الاتصال بمحرك المطابقة مع خيار الفرز اليدوي.
