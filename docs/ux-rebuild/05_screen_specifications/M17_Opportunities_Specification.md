# مواصفة الشاشات: الوحدة M17 — سوق الفرص والمشاريع (Opportunities Marketplace)
## Module Specification: M17 Opportunities Marketplace · P1

**معرفات الشاشات المرجعية:** Q-0641 (Overview ⚓), Q-0643 (Details ⚓), Q-0644 (Create ⚓), Q-0647 (Results ⚓), Q-0669 (Empty ⚓), Q-0671 (Error ⚓)  
**المسار:** `/opportunities/m17`  
**الأدوار المدعومة:** مهندس / باحث عن مشاريع (`u`) · منشأة ناشرة للفرص (`c`)

---

### 1. الغرض ومهمة المستخدم
- استعراض وتصفية فرص العمل والمشاريع والتحديات التقنية المطابقة لمهارات المستخدم البرمجية.
- إبراز الشفافية المالية المسبقة (المكافأة / الراتب / مدة التنفيذ).
- توضيح **«لماذا طوبقت هذه الفرصة معك؟»** بناءً على أدلة الكود الفعلي لا الكلمات الدلالية العشوائية.

---

### 2. التكوين البصري والواجهة الفاتحة (Light-First Visual Composition)
- **أشرطة المقاييس العلوية:** 4 بطاقات إحصائية موجزة: إجمالي الفرص، متوسط نسبة التوافق، مطابقة استثنائية (≥80%)، مواعيد تسليم قريبة.
- **شريط البحث والتصفية الحي:**
  - حقل إدخال واسع للبحث بالاسم أو التقنية (`React`, `FastAPI`, `Docker`).
  - أزرار تصنيف سريعة (Pills): الكل، مشروع مستقل، تحدي تقني، دوام كامل، استشارة، عمل حر.
  - قائمة منسدلة لترتيب النتائج (أعلى مطابقة، الأحدث، أقرب موعد).
- **بطاقة الفرصة (Opportunity Card):**
  - جهة النشر الموثقة مع شارة التحقق الرسمية وموقع العمل (عن بعد / هجين / حضوري مع ذكر المدينة).
  - عنوان الفرصة بحجم `1.15rem` ولون داكن بارز (`#0F172A`).
  - فقرة "لماذا تطابقت؟" بخلفية فيروزية فاتحة لطيفة (`rgba(0, 184, 184, 0.06)`).
  - وسوم المهارات المطلوبة مع مستوى كل مهارة (`متقدم` / `متوسط`).
  - تذييل البطاقة: الأجر المالي الصريح، تاريخ انتهاء التقديم، وزر الإجراء «تقديم العرض».

---

### 3. خلو الواجهة من أكواد التطوير
- تم حظر وإلغاء أي ظهور لأكواد `M17 · Q-0641` أو اختصارات `[Proj]`, `[Chal]`, `[FT]`.
- العناوين مكتوبة باللغة العربية الفصحى السلسة.

---

### 4. شاشات الـ Anchor الستة الخاصة بـ M17
1. **Q-0641 (نظرة عامة Overview ⚓):** سوق الفرص الكامل مع الفلاتر والفرز.
2. **Q-0643 (التفاصيل Details ⚓):** صفحة تفاصيل المشروع، المتطلبات الكاملة، ومقارنة فجوات المهارات.
3. **Q-0644 (إنشاء Create ⚓):** نموذج طرح فرصة أو مشروع جديد من قبل المنشأة.
4. **Q-0647 (النتائج Results ⚓):** عرض نتائج التقديم على الفرصة وموقف العرض المقدم.
5. **Q-0669 (الحالة الفارغة Empty ⚓):** عند عدم العثور على فرص تطابق فلتر معين، مع زر لإلغاء الفلتر واقتراح تحديث المهارات.
6. **Q-0671 (معالجة الخطأ Error ⚓):** صفحة خطأ استرجاع البيانات مع إمكانية التحديث التلقائي.
