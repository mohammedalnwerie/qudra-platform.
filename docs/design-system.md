# QUDRA (قُدرة) — دليل نظام التصميم والهوية البصرية (Design System & Tokens)

> **تاريخ الإصدار:** أكتوبر 2026  
> **الإصدار:** v2.0  
> **اللغات المدعومة:** العربية (افتراضي RTL أصيل) + الإنجليزية (LTR)

---

## 1. فلسفة الهوية البصرية (Visual Identity)

تستلهم هوية "قُدرة" مبادئ **المصداقية، الشفافية، والراحة البصرية العالية (Visual Comfort & Modern Calmness)**:
* **راحة العين والهدوء البصري (Calming & Airy Aesthetics):** استبدال التدرجات الداكنة الثقيلة بخلفيات بيضاء ناعمة ومساحات تنفس واسعة (Whitespace)، مع استخدام درجات رمادي دافئة وأنيقة (`#f8fafc` للخلفيات، `#0f172a` للعناوين).
* **إزالة التشتت المعرفي (De-cluttering & Clean Microcopy):** إزالة المصطلحات الإنجليزية المحشورة بين الأقواس والأكواد البرمجية الزائدة (`P0, P1, P2`) من القوائم الرئيسية لتقديم تجربة مستخدم نقية وفاخرة تليق بمنتج إنتاجي عالمي.
* **البطاقات الناعمة (Soft Card Elevation):** الاستغناء عن الحواف الملونة الفاقعة والسميكة لصالح بطاقات بيضاء نقية ذات ظلال بالغة النعومة، مع أيقونات ملونة لطيفة تبرز القيمة دون صراخ بصري.
* **التحقق الصريح (Honest Semantics):** تمييز بصري ناعم بين ما هو **مُثبت بأدلة (Proven)**، وما هو **مُعلن ذاتياً (Claimed)**، وما هو **فجوة قائمة (Gap)**.
* **اللغة العربية أولاً (Arabic-First RTL):** طباعة عربية متزنة ذات مقروئية عالية (`IBM Plex Sans Arabic` و`Cairo`) وتخطيط منطقي يحافظ على اتساق التدفق البصري.

#### مستويات ثقة الموصلات (Connector Trust Tiers)
* **Official (موثق رسمي):** خلفية بلون Teal باهت، أيقونة درع موثق، وعلامة API رسمي (GitHub OAuth, Credly).
* **User-supplied (مُقدَّم من المستخدم):** خلفية بلون Sky باهت، أيقونة ملف/رفع، إشارة إلى تقرير أو شهادة دورة.
* **Fragile (هش / غير مستقر):** خلفية بلون Amber باهت، أيقونة تنبيه، إشارة إلى رابط عام قابل للتغير أو التوقف.

### 2.3 الأبعاد والمسافات والحواف (Spacing & Radii)

* **مقياس المسافات:** 4px (xs), 8px (sm), 12px (md), 16px (base), 24px (lg), 32px (xl), 48px (2xl).
* **نصف القطر (Border Radius):**
  - شارات وأزرار دائرية: `9999px` (Full Pill)
  - البطاقات والحاويات: `12px` (Standard Rounded)
  - النوافذ واللوحات المنبثقة: `16px` (Dialog Rounded)
  - حقول الإدخال والأزرار: `8px` (Input Rounded)
* **الظلال والارتفاع (Elevation):**
  - **Flat / Low:** `box-shadow: 0 1px 3px 0 rgba(0, 0, 0, 0.05)`
  - **Elevated Card:** `box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05), 0 2px 4px -2px rgba(0, 0, 0, 0.05)`
  - **Floating Drawer & Modal:** `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.1)`

## 3. المكونات المشتركة وقواعد التفاعل (Core UI Components)

1. **شارة الدليل (Evidence Badge):**
   - تعرض الأيقونة + النص الصريح (مثال: `✓ مُثبت` أو `⚡ مُعلن` أو `○ فجوة`).
   - لا يجوز أبداً الاعتماد على اللون بمفرده دون أيقونة ونص مراعاةً لسهولة الوصول (Accessibility).
2. **درج التفسير (Explain Drawer):**
   - درج ينزلق من اليسار (في RTL) أو اليمين (في LTR) مع خلفية معتمة خفيفة.
   - يتضمن: نسبة التوافق، توزيع أوزان الأدلة (Feature Importance Bar)، وتوصية عملية فورية لتحسين النتيجة.
3. **بطاقة الجواز (Passport Capability Card):**
   - تعرض المهارة، مستوى الإتقان، رابط الدليل الأصلي، والجهة المانحة/الموثقة.
   - زر مباشر لنسخ رابط الدليل أو قراءته آلياً بصيغة JSON.
4. **شريط التنقل العلوي والجانبي (Bilingual Navbar & Sidebar):**
   - دعم التبديل الفوري بين العربية (RTL) والإنجليزية (LTR).
   - مبدل الأدوار السريع (طالب، مستقل، شركة، مراجع) لاختبار الشاشات من زاوية كل مستخدم.
   - فاحص الشاشات (Screen Navigator) للوصول لأي شاشة من شاشات الـ1,040.
5. **مُركِّب الفرق (Team Composer Grid):**
   - تمثيل بصري لتكامل المهارات؛ بطاقات مصغرة للمرشحين مع مؤشر تغطية متطلبات المشكلة.
6. **محرر إدخال المشكلة (Problem Analyzer Input):**
   - مساحة نصية مع تحليل فوري ذكي لاستخراج القدرات والميزانية المقترحة والإطار الزمني.

## 4. قواعد التصميم المتجاوب ودعم RTL/LTR الأصيل

* **التجاوب الكامل:**
  - **شاشات سطح المكتب العريضة (>1280px):** عرض متعدد الأعمدة (الشريط الجانبي + المحتوى الرئيس + لوحة الإجراءات السريعة).
  - **أجهزة الكمبيوتر المحمولة (1024px - 1280px):** عمودان متوازنان مع لوحة قابلة للطي.
  - **الأجهزة اللوحية (768px - 1023px):** شريط جانبي ينسدل بالضغط، بطاقات تتوزع عمودياً.
  - **الهواتف الذكية (<768px):** عمود واحد، شريط ملاحة سفلي أو قائمة همبرغر، أهداف لمس لا تقل عن 44px × 44px لمنع أخطاء الضغط.
* **قواعد RTL الصارمة:**
  - اتجاه القراءة من اليمين إلى اليسار تلقائياً.
  - أسهم التقدم ومؤشرات الخطوات تعكس اتجاهها (`ChevronRight` يتحول لـ `ChevronLeft`).
  - أيقونات الحالة الموضوعية (الصح، الساعة، التنبيه) لا تعكس اتجاهها.
  - الحفاظ على الترقيم والعملات بنسق محلي واضح دون تشويه.
